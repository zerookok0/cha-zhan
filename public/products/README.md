# 给盏配实拍图（白底）

## 能不能「随便上一张图」照样滑动？

**不能。** 直接把 `<img>` 塞进卡片会破坏横向拖动，原因有两个：

1. **浏览器把图片当可拖拽对象。** 按住图片拖动时，浏览器触发的是原生
   HTML5 drag，不是滚动 —— 光标会变成「拖一张图走」的样子，轨道纹丝不动。
2. **图片会吃掉指针事件。** 我们靠容器上的 `pointerdown / pointermove`
   算位移，指针落在图片上时事件仍会冒泡，但原生 drag 一起手就会打断序列。

本项目已经把这两个坑都堵上了，所以你只要**按下面的方式填图**，
拖动、点击、加购全部照旧：

- 图片层 `pointer-events: none`（指针直接穿透到容器）
- `draggable={false}` 关掉原生拖拽
- 全局 `img { -webkit-user-drag: none }` 兜底

## 怎么放图

1. 把白底照片放进 `public/products/`，例如 `public/products/yelan.jpg`。
2. 在 `src/lib/data.ts` 里给对应盏加 `photo` 字段：

```ts
{
  id: 'yelan',
  name: '夜岚',
  photo: '/products/yelan.jpg',   // ← 加这一行
  // …
}
```

3. 刷新页面即可。没填 `photo` 的盏继续使用代码绘制的版本；
   **图片 404 或加载失败会自动退回绘制版**，不会出现破图。

## 关于白底

白底照片直接铺在深色页面上会显得像「缺了一块」。所以图片不是裸贴的，
而是放在一块暖白的台面上（`.photo-stage`），配合 `mix-blend-mode: multiply`
让纯白背景融进台面，只留下杯体本身 —— 接近拍卖图录的产品页观感。

拍图建议：

- 纯白或浅米色背景，避免带阴影的灰白渐变
- 俯视 45°，能看清内壁釉色
- 单张方形（如 1200×1200）最好，`object-contain` 会等比缩放不裁切
- 不要自己在图上加白边或水印，前端已留 7% 内边距

## 关于「转一圈」

这一条要提前说清，免得做完之后落差：

**照片是平的，转不出背面。** 现在绘制版的旋转，是真的在转矢量釉面
（`BowlArt` 用 `rotate` 重建另一侧的纹理）。一张照片没有第二面，
强行转只会把图转歪，看起来像出错了。

所以单张图时页面**不会假装能转**：

- 光标不是 `grab`，拖它不会转
- 详情页左上角显示「正面」，而不是会误导人的 `0°`
- 换成会跟着指针走的视差和高光 —— 静态图也有生气，但不撒谎

### 如果你想要「真的能转」

给我同一只盏的 **多角度照片**（3–12 张，绕一圈均匀拍），
用 `photos` 字段填进去：

```ts
{
  id: 'yelan',
  name: '夜岚',
  photo: '/products/yelan-01.jpg',
  photos: [
    '/products/yelan-01.jpg',
    '/products/yelan-02.jpg',
    '/products/yelan-03.jpg',
    '/products/yelan-04.jpg',
  ],
}
```

给了两张以上，按住左右拖就会**切换视角** —— 每拖 72px 换一张，
拖满一圈走完所有角度，观感上就是转了一圈。这时：

- 光标变 `grab`
- 详情页角度读数恢复成真实角度
- 卡片按钮显示「转一转、看光照」
- 底部出现视角小圆点指示

只填 `photo` 一张时，以上四项自动退回「不能转」的措辞，不会有假承诺。
